# Memory and mutation safety coverage

This matrix maps `docs/specs/memory-and-mutation-safety.md` to its automated
coverage. Every normative rule, required rejection, and conformance item has
an owning check. Test names are quoted so failures can be found without
depending on line numbers.

## Required rejections and diagnostics

| Rejection                                                             | Diagnostic/behavior owner                                                                                              |
| --------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| Active shared/exclusive and exclusive/exclusive overlap               | `TY0048`; `CON` checks both active-shared and active-mutable wording; `B` overlap cases                                |
| Forming a mutable borrow from shared access                           | `TY0050`; `B` “rejects creating a mutable borrow from shared access”                                                   |
| Explicit borrow escaping a local origin or plain return               | `TY0051`; `CON` checks canonical escape text and source span                                                           |
| Missing, invalid, or underspecified region/borrow contract            | `TY0054`; `CON` checks missing `returns_from`; `B` invalid mapping, false disjointness, excess read/write/result tests |
| Borrowed aggregate stored in pre-existing or longer-lived storage     | `TY0051`; `B` direct-storage, field-storage, and module-storage rejection tests                                        |
| Borrow or mutable reborrow crossing suspension                        | `TY0051`; `B` effect-operation and resumable-boundary tests                                                            |
| Escaping mutable or explicit capture                                  | `TY0051`; `B` mutable and explicit closure-capture rejection tests                                                     |
| Opaque call with unprovable borrowed-result origin                    | `TY0051`; `B` “rejects opaque calls that cannot prove nested borrowed-result origins”                                  |
| Unstable, incomplete, escaping, or suspending runtime-guard candidate | Compile-time `TY0048`/`TY0051`; `B` guard rejection tests at the end of the suite                                      |
| Equal runtime guard identities                                        | Deterministic runtime panic naming argument 1 and argument 2; `CON` and `PERF`                                         |
| SharedCell callback escape, retention, storage, or suspension         | `TY0051`; `B` SharedCell callback restriction group                                                                    |
| SharedCell runtime conflict                                           | Deterministic panic or typed `SharedCellBorrowError`; `STD` and `INT`                                                  |
